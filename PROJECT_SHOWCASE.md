# Genre-Based File Organizer - Project Showcase

## LinkedIn Project Details

### Project Name
**Genre-Based File Organizer** (Intelligent Document Clustering System)

### Description
Developed a production-ready desktop application that automatically organizes documents by semantic content using Natural Language Processing and machine learning. The system reads and understands document content (Word, Excel, PowerPoint) without relying on filenames, using DistilBERT transformer models for semantic embeddings and FAISS for efficient clustering.

**Technical Implementation:**
- Built professional GUI application using Tkinter with multi-threaded architecture for responsive user experience
- Implemented text extraction pipeline for .docx, .xlsx, and .pptx files using python-docx, openpyxl, and python-pptx
- Integrated DistilBERT transformer model to generate 768-dimensional semantic embeddings capturing document meaning
- Utilized FAISS (Facebook AI Similarity Search) library with K-means clustering for intelligent document grouping
- Developed industrial-grade build system creating self-contained executables (like Chrome/VS Code) with embedded Python interpreter and all dependencies
- Created professional Windows installer using Inno Setup with desktop shortcuts and uninstaller
- Implemented comprehensive logging system and real-time progress callbacks for GUI integration

**Key Achievements:**
- Processes 100-500 files/minute for text extraction; 10-20 files/minute for embedding generation (CPU)
- Built cross-platform support (Windows .exe, macOS .app, Linux binary) using PyInstaller
- Developed complete documentation suite (15,000+ words) including user guides, technical architecture, build instructions, and distribution strategies
- Followed modern Python packaging standards (PEP 518/517) with pyproject.toml configuration
- Automated build pipeline with 6-step process: clean → verify → test → build → validate → package

**Technologies:**
- NLP & ML: DistilBERT (Hugging Face Transformers), FAISS, K-means clustering, PyTorch
- Document Processing: python-docx, openpyxl, python-pptx, NumPy
- GUI & Distribution: Tkinter, PyInstaller, Inno Setup
- Development: Python 3.8+, pytest, black, mypy, pylint

## LinkedIn Post - Option 2 (Problem-Solution Focus)

💡 **Ever spent hours organizing hundreds of documents by topic? I built an AI to do it automatically.**

I created a desktop application that reads document content (Word, Excel, PowerPoint) and intelligently groups related files together using Natural Language Processing.

**The Problem:**
Manual file organization is tedious and inconsistent. Filenames don't capture content, and folders quickly become messy.

**My Solution:**
An intelligent organizer using DistilBERT transformer models to understand document semantics, combined with FAISS clustering to group similar content automatically.

**How It Works:**
1. Scans your documents and extracts text
2. Converts content to semantic embeddings using DistilBERT
3. Clusters similar documents using FAISS + K-means
4. Organizes files into semantic groups

**Technical Stack:**
- NLP: DistilBERT (Hugging Face Transformers), FAISS
- Processing: python-docx, openpyxl, python-pptx
- Interface: Tkinter GUI with multi-threading
- Distribution: PyInstaller + Inno Setup for professional installer

**Real-World Impact:**
Processes 100-500 files/minute and works completely offline. Built as a self-contained executable that runs on any Windows/Mac/Linux machine without Python installation.

The project taught me invaluable lessons about production ML systems, software packaging, and building tools that solve real problems.
